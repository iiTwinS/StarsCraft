What is StarsCraft?

StarsCraft is a Moroccan Minecraft server available for both Java and Bedrock (offline/cracked) players. It focuses on fast-paced 1v1 battles across custom PvP maps and exclusive modes like ElytraFight, CrystalPvP, SMPKitPvP, NethPotFight, AxeShieldDuel, CartBattle, and MaceFight. Each mode delivers a unique combat style and competitive experience. The server offers smooth crossplay, optimized performance, and an active community dedicated to skill-based gameplay and constant updates.

Story about StarsCraft

Back in 2018, I used to play free versions of Minecraft. In 2020, I downloaded a game called Master Craft, version 0.14.3, and I also had another game called Craftsman, version 0.15.10. I was very well-known in the Arab community under the name Mr Twins. One day, I decided to create a server called StarsSMP, which had a clear and simple concept. Later, I launched another server named StarsGames, which featured all kinds of mini-games such as Bed Wars and MLG Block, though these games are no longer available. From these earlier projects and ideas, the name StarsCraft was born.
